# GenieRedux-G (CoinRun) — verified architecture

Ground truth: the two downloaded checkpoints (gitignored scratch), keys+shapes
read directly with torch. Tokenizer 514 tensors / 101.7M; dynamics 372 tensors
/ 80.8M. This is the name-map and shape contract the `wm-genie` import must
satisfy with full coverage (hard error on any missing/extra/unmapped tensor,
per `glm/src/import.rs` discipline).

## Shared constants
- `dim` = 512 (tokenizer residual) / 519 (dynamics residual = 512 + 7 one-hot
  action channels concatenated per token).
- attention: 8 heads × head_dim 64. `to_q: dim→512`, `to_kv: dim→1024` (fused
  k|v, 512 each), `to_out: 512→dim`. QK-norm: `q_scale,k_scale` are `[64]`
  (per-dim), applied after L2-normalizing each head over head_dim; constant
  attention scale 8. → `wm_core::attn::BiasedAttn` (l2norm_scale + biased scores).
- per-head additive score bias from a small MLP `net: Linear(2→H_hidden)→
  LeakyReLU→Linear(H_hidden→8)`; H_hidden = 512 (tokenizer `spatial_rel_pos_bias`)
  / 64 (dynamics `maskgit.continuous_pos_bias`). Output 8 = per-head bias fed to
  `attn_scores_bidir_bias` (spatial) — relative positions are the grid (i,j).
- PEG: `*_peg.dsconv` = depthwise conv3d `[C,1,3,3,3]` + bias → `dwconv3d`.
  Temporal PEG uses causal (asymmetric (2,0)) padding (host pre-pad).
- GEGLU FF: `ff.0` LayerNorm(dim) → `ff.1` Linear(dim→2·h) → GEGLU (split h|h,
  gelu(a)·b) → `ff.4` Linear(h→dim). Tokenizer h=1365 (=round(512·8/3)).
- norm/context_norm: LayerNorm `{gamma,beta}` (context = x for self-attention).

## STBlock (`encoder|decoder|maskgit.transformer` `.layers.N.0`)
Each block runs the pair, spatial then temporal; each sub-step is
`peg → attention(QK-norm, biased, scale 8) → GEGLU-ff`, residual around each:
- `spatial_peg` (dwconv3d over H,W per frame) → `spatial_attention` (over the
  H·W tokens of each frame; bidirectional; ContinuousPositionBias) → `spatial_ff`
- `temporal_peg` (causal dwconv3d over T) → `temporal_attention` (over T per
  spatial location; **causal**) → `temporal_ff`
"st"/"ts" = reshape which axis is the attention sequence vs. batch.

## Tokenizer (frozen ST-ViViT + cosine-VQ), 101.7M
- patchify 4×4×3 = 48 per token: `to_patch_emb[_first_frame]` =
  LayerNorm(48) → Linear(48→512) → LayerNorm(512). Two variants: first frame vs.
  the rest (temporal-causal patch handling).
- `encoder.layers.0..7` (8 STBlocks) → `encoder.norm_out` (LayerNorm 512).
- VQ: `vq.project_in` 512→32, `vq._codebook.embed` `[1,1024,32]` (1024 codes,
  dim 32, COSINE similarity → `vq_argmax_dot` on L2-normalized inputs),
  `vq.project_out` 32→512. EMA buffers `cluster_size`,`embed_avg` present
  (frozen at inference). → `wm_core::vq`.
- `decoder.layers.0..7` (8 STBlocks) → `decoder.norm_out` →
  `to_pixels[_first_frame]` Linear(512→48) → unpatch to RGB.

## Dynamics (guided MaskGIT), 80.8M
- `maskgit.token_emb` `[1025,512]` (1024 codes + 1 MASK) ; `maskgit.pos_emb`
  `[4000,512]` learned. Action: 7 one-hot channels concatenated → residual dim
  519.
- `maskgit.transformer.layers.0..11` (12 STBlocks at dim 519) →
  `transformer.norm_out` → `maskgit.to_logits` 519→1024 (code logits).
- sampling: guided MaskGIT decode (host loop): iterative unmask by confidence,
  cosine schedule, Gumbel/top-k — logits read back, sampling is a host decision.

## Build order (kernels all present + gradchecked)
1. `wm-genie` crate: STBlock composing `wm_core::attn::BiasedAttn` + `dwconv3d`
   PEG + GEGLU (gelu∘mul) + LayerNorm + matmul-linears; "st"/"ts" reshapes.
2. import: name-map for both checkpoints (514 / 372 tensors), full-coverage.
3. tokenizer forward → VQ round-trip (PSNR gate) using `wm_core::vq`.
4. dynamics forward + MaskGIT sampler.
5. CoinRun ingest (jpg frames + actions.json, 7 actions) → `wm-ingest`.
6. `WorldModel` wrap → interactive SDL/WASD.

Parity: dump per-layer activations from the GenieRedux repo (case-study
`neurips` branch) via `scripts/parity-dump/genie.py`, assert allclose in
`wm-genie` tests — same discipline as DIAMOND.
