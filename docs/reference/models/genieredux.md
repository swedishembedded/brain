# GenieRedux-G (not yet playable)

A CoinRun world model alongside [DIAMOND](diamond.md) (compared on the
[world models overview](world-models.md)): a ST-transformer (QK-normalized
biased attention, GEGLU FFN, PEG) over a tokenizer/MaskGIT dynamics model.

The tokenizer/MaskGIT dynamics are still in progress - this architecture is
not playable end to end yet. Model id (once served): package
`brain-genieredux`.
