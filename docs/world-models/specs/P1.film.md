## 1. Purpose

FiLM (feature-wise linear modulation) and adaLN-style conditioning, the way
DIAMOND's UNet consumes noise/action embeddings and the way DiT-style blocks
consume per-frame conditioning:

- **Channel variant** (`film_chan*`): NCHW activations, one `(scale, shift)`
  pair per `(n, c)` — the classic FiLM used in DIAMOND's conv blocks. The
  modulation is `y = x * (1 + s) + b` (the "+1" residual parameterization:
  a zero-initialized conditioning projection yields the identity map).
- **Row variant** (`film_row*`): `[R, D]` token rows, one `(scale, shift)`
  vector of width `D` per *condition group* of `rows_per_cond` consecutive
  rows. With `rows_per_cond = tokens-per-frame` this is the per-frame
  diffusion-forcing conditioning path (each frame has its own sigma
  embedding); with `rows_per_cond = R` it degenerates to a single adaLN
  modulation for the whole sequence.
- **Gated residual** (`gate_row*`): `y = x + g ⊙ h`, adaLN-Zero's gated
  branch merge (`g` per condition group, broadcast over the group's rows).

`s`, `b`, `g` are ACTIVATIONS (outputs of a conditioning linear/MLP), not
trainable parameters of this unit — so every backward output here OVERWRITES
a fresh SSA buffer (`=`, never `+=`); grad accumulation, when needed, is the
caller's job via the existing `add` kernel. This deliberately differs from
`gn`'s `dgb` (a parameter grad, accumulated).

**dx of `gate_row` is the identity**: `∂y/∂x = 1`, so `dx = dy` element-wise.
NO kernel is provided or needed — callers reuse the upstream `dy` buffer
directly, or the existing `add` kernel when the residual grad must be
accumulated into an existing grad buffer. This is a documented contract, not
an omission.

All kernels: fp32 only, uniform `Params` at `@binding(0)`, ≤ 4 storage
buffers, `@workgroup_size(64)`, no atomics / barriers / f16, no f32 `%`
(u32 `%` and `/` are fine), 2D-grid-safe linear thread index
`gidx = gid.y * (nwg.x * 64u) + gid.x`, single source (no per-backend forks).

## 2. Shapes, layouts, index conventions

### 2.1 Channel variant (NCHW)

Tensor `x[N, C, H, W]`, row-major NCHW:

```
idx(n,c,h,w) = ((n*C + c)*H + h)*W + w
from element idx:  hw = H*W;  c = (idx / hw) % C;  n = idx / (C * hw)
```

Buffers (all `array<f32>`):

| name  | length    | layout                                                            |
|-------|-----------|-------------------------------------------------------------------|
| `x`   | `N*C*H*W` | NCHW input                                                        |
| `sb`  | `N*2C`    | ONE packed buffer, per row `n`: scale first, shift second — `s[n,c] = sb[n*2C + c]`, `b[n,c] = sb[n*2C + C + c]` |
| `y`   | `N*C*H*W` | NCHW output (fresh SSA buffer)                                    |
| `dy`  | `N*C*H*W` | upstream gradient                                                 |
| `dx`  | `N*C*H*W` | input gradient (OVERWRITTEN)                                      |
| `dsb` | `N*2C`    | same packing as `sb`: `ds` in the first `C` of each row, `db` in the second `C` (OVERWRITTEN) |

### 2.2 Row variant ([R, D] rows)

Tensor `x[R, D]`, row-major:

```
idx(r,d) = r*D + d;      from element idx:  r = idx / D;  d = idx % D
condition group of row r:  g(r) = r / rows_per_cond        (u32 division)
number of groups:          NC  = R / rows_per_cond          (REQUIRES R % rows_per_cond == 0)
```

Buffers:

| name  | length     | layout                                                           |
|-------|------------|------------------------------------------------------------------|
| `x`   | `R*D`      | input rows                                                       |
| `sb`  | `NC*2D`    | per condition group `k`: `s[k,d] = sb[k*2D + d]`, `b[k,d] = sb[k*2D + D + d]` |
| `y`   | `R*D`      | output (fresh SSA buffer)                                        |
| `dy`  | `R*D`      | upstream gradient                                                |
| `dx`  | `R*D`      | input gradient (OVERWRITTEN)                                     |
| `dsb` | `NC*2D`    | same packing as `sb` (OVERWRITTEN)                               |

### 2.3 Gated residual ([R, D] rows)

Same row/group conventions as §2.2 (`gi(r) = r / rows_per_cond`,
`NC = R / rows_per_cond`), but the gate is a plain `[NC, D]` buffer (no
packing — there is only one modulation vector):

| name | length  | layout                                       |
|------|---------|----------------------------------------------|
| `x`  | `R*D`   | residual-stream input                        |
| `g`  | `NC*D`  | gate: `g[k,d] = g[k*D + d]`                  |
| `h`  | `R*D`   | branch output being gated                    |
| `y`  | `R*D`   | output (fresh SSA buffer)                    |
| `dy` | `R*D`   | upstream gradient                            |
| `dh` | `R*D`   | branch gradient (OVERWRITTEN)                |
| `dg` | `NC*D`  | gate gradient (OVERWRITTEN)                  |

Divisibility: the kernels ASSUME `R % rows_per_cond == 0` (behavior with a
ragged final group is undefined and must be unreachable — enforced by
`FilmRowDims::new`, §8).

## 3. Math

### 3.1 film_chan

Forward, for every element `i = (n,c,h,w)`:

```
y_i = x_i * (1 + s[n,c]) + b[n,c]
```

Backward, given `dy = dL/dy` (all exact — the map is affine in each input):

```
dx_i     = dy_i * (1 + s[n,c])                    // ∂y/∂x = 1+s
ds[n,c]  = Σ_{h,w} dy_{n,c,h,w} * x_{n,c,h,w}     // ∂y/∂s = x
db[n,c]  = Σ_{h,w} dy_{n,c,h,w}                   // ∂y/∂b = 1
```

### 3.2 film_row

Forward, for every element `(r,d)`, with `k = g(r) = r / rows_per_cond`:

```
y[r,d] = x[r,d] * (1 + s[k,d]) + b[k,d]
```

Backward:

```
dx[r,d]  = dy[r,d] * (1 + s[g(r),d])
ds[k,d]  = Σ_{r : g(r)=k} dy[r,d] * x[r,d]        // rows_per_cond terms
db[k,d]  = Σ_{r : g(r)=k} dy[r,d]
```

### 3.3 gate_row

Forward, `k = gi(r) = r / rows_per_cond`:

```
y[r,d] = x[r,d] + g[k,d] * h[r,d]
```

Backward:

```
dx[r,d]  = dy[r,d]                                 // IDENTITY — no kernel (§1)
dh[r,d]  = dy[r,d] * g[gi(r),d]
dg[k,d]  = Σ_{r : gi(r)=k} dy[r,d] * h[r,d]
```

Useful properties (used as tests):
- `s = b = 0` ⇒ `film_*` is the identity: `y = x * 1.0 + 0.0 = x` (exact in
  fp32 up to `-0.0 → +0.0`; `==` equality holds always).
- `g = 0` ⇒ `gate_row` is the identity on `x` (`==` equality).
- Everything is bilinear/affine, so central finite differences are exact up
  to fp32 rounding — FD checks have no truncation-error excuse to miss.

## 4. Kernel contracts

Common: `@workgroup_size(64)`, thread index
`gidx = gid.y * (nwg.x * 64u) + gid.x`, bounds-check and return. Uniform
`Params` at `@group(0) @binding(0)`. Channel kernels share
`Params { N, C, H, W }`; row/gate kernels share
`Params { R, D, rows_per_cond }` (a field may be unused by a particular
kernel — keep the layout uniform within each family). Host passes params as
`&[u32]` in struct field order. All outputs are written with `=`
(OVERWRITE), each output element by exactly one thread.

### 4.1 `film_chan` — one thread per element, `N*C*H*W` threads

```
Params { N, C, H, W }
b1 x  : read        [N*C*H*W]
b2 sb : read        [N*2C]
b3 y  : read_write  [N*C*H*W]
```

`c = (idx/(H*W)) % C`, `n = idx/(C*H*W)`;
`y[idx] = x[idx] * (1.0 + sb[n*2C + c]) + sb[n*2C + C + c]`.

### 4.2 `film_chan_dx` — one thread per element, `N*C*H*W` threads

```
Params { N, C, H, W }
b1 dy : read        [N*C*H*W]
b2 sb : read        [N*2C]
b3 dx : read_write  [N*C*H*W]
```

`dx[idx] = dy[idx] * (1.0 + sb[n*2C + c])`. Reads ONLY the scale half.

### 4.3 `film_chan_dsb` — one thread per (n,c), `N*C` threads

```
Params { N, C, H, W }
b1 x   : read        [N*C*H*W]
b2 dy  : read        [N*C*H*W]
b3 dsb : read_write  [N*2C]
```

Thread `t`: `n = t / C`, `c = t % C`. ONE sequential loop over `(h,w)` in
ascending order accumulating BOTH sums:

```
ds += dy[((n*C+c)*H+h)*W+w] * x[same idx];   db += dy[same idx]
```

then writes both halves: `dsb[n*2C + c] = ds`, `dsb[n*2C + C + c] = db`.
Each thread owns exactly two disjoint output slots.

### 4.4 `film_row` — one thread per element, `R*D` threads

```
Params { R, D, rows_per_cond }
b1 x  : read        [R*D]
b2 sb : read        [NC*2D]
b3 y  : read_write  [R*D]
```

`r = idx/D`, `d = idx%D`, `k = r / rows_per_cond`;
`y[idx] = x[idx] * (1.0 + sb[k*2D + d]) + sb[k*2D + D + d]`.

### 4.5 `film_row_dx` — one thread per element, `R*D` threads

```
Params { R, D, rows_per_cond }
b1 dy : read        [R*D]
b2 sb : read        [NC*2D]
b3 dx : read_write  [R*D]
```

`dx[idx] = dy[idx] * (1.0 + sb[k*2D + d])`.

### 4.6 `film_row_dsb` — one thread per (cond, d), `NC*D` threads

```
Params { R, D, rows_per_cond }
b1 x   : read        [R*D]
b2 dy  : read        [R*D]
b3 dsb : read_write  [NC*2D]
```

Thread `t`: `k = t / D`, `d = t % D`. Loop `i` in `0..rows_per_cond`
(ascending), `r = k*rows_per_cond + i`:

```
ds += dy[r*D + d] * x[r*D + d];   db += dy[r*D + d]
```

writes `dsb[k*2D + d] = ds`, `dsb[k*2D + D + d] = db`.

### 4.7 `gate_row` — one thread per element, `R*D` threads

```
Params { R, D, rows_per_cond }
b1 x : read        [R*D]
b2 g : read        [NC*D]
b3 h : read        [R*D]
b4 y : read_write  [R*D]
```

`y[idx] = x[idx] + g[k*D + d] * h[idx]` (exactly 4 storage buffers — at the
limit; this is why `dx` must not be a kernel of this family).

### 4.8 `gate_row_dh` — one thread per element, `R*D` threads

```
Params { R, D, rows_per_cond }
b1 dy : read        [R*D]
b2 g  : read        [NC*D]
b3 dh : read_write  [R*D]
```

`dh[idx] = dy[idx] * g[k*D + d]`.

### 4.9 `gate_row_dg` — one thread per (cond, d), `NC*D` threads

```
Params { R, D, rows_per_cond }
b1 dy : read        [R*D]
b2 h  : read        [R*D]
b3 dg : read_write  [NC*D]
```

Thread `t`: `k = t / D`, `d = t % D`. Loop `i` in `0..rows_per_cond`
(ascending), `r = k*rows_per_cond + i`: `s += dy[r*D+d] * h[r*D+d]`;
writes `dg[k*D + d] = s`.

## 5. Dispatch order

Forward: each of `film_chan` / `film_row` / `gate_row` is a single
independent dispatch (fresh output buffer, SSA).

Backward: within one family, `*_dx` (or `gate_row_dh`) and `*_dsb`
(or `gate_row_dg`) have disjoint write sets and no mutual data dependency —
they may share one `gpu.submit` in either order. The `gate_row` residual
grad `dx = dy` needs no dispatch at all.

## 6. Hand-computed references

Every value below is an exact binary fraction (dyadic rational with small
exponent), and every reduction has ≤ 4 exactly-representable terms, so ALL
comparisons in the reference tests are EXACT: assert with `==` on f32 (no
tolerance). Show your work is shown.

### 6.1 film_chan, `N=1, C=2, H=W=2`

Input `x` (flat index `c*4 + h*2 + w`):

```
c0 = [ 1, 2, 3, 4]
c1 = [-1, 0, 2, 3]
```

`sb[N,2C] = sb[1,4] = [s0, s1, b0, b1] = [0.5, -1.5, 0.25, 2.0]`
⇒ `1+s0 = 1.5`, `1+s1 = -0.5`.

Forward `y = x*(1+s) + b`:

```
c0: 1.5·1+0.25 = 1.75;  1.5·2+0.25 = 3.25;  1.5·3+0.25 = 4.75;  1.5·4+0.25 = 6.25
c1: −0.5·(−1)+2 = 2.5;  −0.5·0+2 = 2.0;    −0.5·2+2 = 1.0;     −0.5·3+2 = 0.5
```

Expected `y = [1.75, 3.25, 4.75, 6.25,  2.5, 2.0, 1.0, 0.5]`.

Backward, upstream `dy`:

```
dy_c0 = [1, -1, 2, 0]      dy_c1 = [0.5, 1, -1, 2]
```

`film_chan_dx` (`dx = dy·(1+s)`):

```
dx_c0 = 1.5·[1,−1,2,0]   = [ 1.5, −1.5, 3.0,  0.0]
dx_c1 = −0.5·[0.5,1,−1,2] = [−0.25, −0.5, 0.5, −1.0]
```

`film_chan_dsb`:

```
ds0 = 1·1 + (−1)·2 + 2·3 + 0·4       = 1 − 2 + 6 + 0   = 5.0
ds1 = 0.5·(−1) + 1·0 + (−1)·2 + 2·3  = −0.5 + 0 − 2 + 6 = 3.5
db0 = 1 − 1 + 2 + 0                  = 2.0
db1 = 0.5 + 1 − 1 + 2                = 2.5
```

Expected `dsb = [5.0, 3.5, 2.0, 2.5]` (packing `[ds0, ds1, db0, db1]`).

### 6.2 film_row, `R=4, D=2, rows_per_cond=2` (⇒ `NC=2`)

Input rows `x` (flat index `r*2 + d`):

```

r1 = [ 3,  −1]      r3 = [−2,  1]
```

`sb[NC,2D] = sb[2,4]`, per group `[s_d0, s_d1, b_d0, b_d1]`:

cond0 (rows 0,1): [ 0.5, −1.0, 1.0,  0.5]   ⇒ 1+s = [1.5, 0.0]
cond1 (rows 2,3): [−0.5,  2.0, 0.0, −1.0]   ⇒ 1+s = [0.5, 3.0]

r0: [1·1.5+1.0,  2·0.0+0.5]  = [ 2.5,  0.5]
r1: [3·1.5+1.0, −1·0.0+0.5]  = [ 5.5,  0.5]

Backward, upstream `dy`:

```
r0 = [ 1,   0]      r2 = [0.5, 1]
r1 = [−1,   2]      r3 = [ 2, −1]
```

```

r1: [−1·1.5,   2·0.0] = [−1.5,  0.0]

```

`gate_row_dh` (`dh = dy·g[gi(r),d]`):

## 7. Host API (`crates/wm-core/src/film.rs`)

Crate `brain-wm-core` (lib name `wm_core`) — created in parallel by units
P1.gn / P1.worldmodel-trait; this unit contributes the `film` module (merge
by union of `pub mod` lines + union of Cargo deps). Workspace member +
default-member + `workspace.dependencies` entry (identical hunks to P1.gn's,
so the merge is clean). Depends on `brain-gpu-core`, `brain-kernels`.

```rust

#[derive(Clone, Copy, Debug, PartialEq)]
pub struct FilmChanDims { pub n: u32, pub c: u32, pub h: u32, pub w: u32 }

impl FilmChanDims {
    pub fn new(n: u32, c: u32, h: u32, w: u32) -> Result<FilmChanDims, String>;
        // Err if any of n,c,h,w == 0
    pub fn elems(&self) -> u32;    // n*c*h*w   (threads for film_chan / film_chan_dx)
    pub fn pairs(&self) -> u32;    // n*c       (threads for film_chan_dsb)
    pub fn sb_len(&self) -> u64;   // 2*n*c     (f32 elements of sb / dsb)
}

/// Dims of one row-FiLM / gate site ([R,D] rows, grouped conditioning).
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct FilmRowDims { pub r: u32, pub d: u32, pub rows_per_cond: u32 }

impl FilmRowDims {
    pub fn new(r: u32, d: u32, rows_per_cond: u32) -> Result<FilmRowDims, String>;
        // Err if any == 0, or r % rows_per_cond != 0
    pub fn elems(&self) -> u32;    // r*d              (threads, per-element kernels)
    pub fn conds(&self) -> u32;    // r/rows_per_cond  (NC)
    pub fn cond_elems(&self) -> u32; // conds()*d      (threads, dsb/dg kernels)
    pub fn sb_len(&self) -> u64;   // 2*conds()*d
    pub fn g_len(&self) -> u64;    // conds()*d
}

    pub row: usize,  pub row_dx: usize,  pub row_dsb: usize,

}

impl Film {
    /// (name, source) pairs for Gpu::new, order matching Film::seq():
    /// ["film_chan","film_chan_dx","film_chan_dsb","film_row","film_row_dx",
    ///  "film_row_dsb","gate_row","gate_row_dh","gate_row_dg"]
    pub fn kernel_sources() -> [(&'static str, &'static str); 9];
    /// Film with indices 0..=8 matching kernel_sources() order.
    pub fn seq() -> Film;

    // Single-dispatch step builders; the caller submits (SSA outputs,
    // OVERWRITE semantics — see §1/§4). d must come from the validated ctor.
    pub fn step_chan(&self, gpu: &Gpu, d: &FilmChanDims,
        x: &DeviceBuffer, sb: &DeviceBuffer, y: &DeviceBuffer) -> Step;
    pub fn step_chan_dx(&self, gpu: &Gpu, d: &FilmChanDims,
        dy: &DeviceBuffer, sb: &DeviceBuffer, dx: &DeviceBuffer) -> Step;
    pub fn step_chan_dsb(&self, gpu: &Gpu, d: &FilmChanDims,
        x: &DeviceBuffer, dy: &DeviceBuffer, dsb: &DeviceBuffer) -> Step;

    pub fn step_row(&self, gpu: &Gpu, d: &FilmRowDims,
        x: &DeviceBuffer, sb: &DeviceBuffer, y: &DeviceBuffer) -> Step;
    pub fn step_row_dx(&self, gpu: &Gpu, d: &FilmRowDims,
        dy: &DeviceBuffer, sb: &DeviceBuffer, dx: &DeviceBuffer) -> Step;
    pub fn step_row_dsb(&self, gpu: &Gpu, d: &FilmRowDims,
        x: &DeviceBuffer, dy: &DeviceBuffer, dsb: &DeviceBuffer) -> Step;

    pub fn step_gate(&self, gpu: &Gpu, d: &FilmRowDims,
        x: &DeviceBuffer, g: &DeviceBuffer, h: &DeviceBuffer,
        y: &DeviceBuffer) -> Step;
    pub fn step_gate_dh(&self, gpu: &Gpu, d: &FilmRowDims,
        dy: &DeviceBuffer, g: &DeviceBuffer, dh: &DeviceBuffer) -> Step;
    pub fn step_gate_dg(&self, gpu: &Gpu, d: &FilmRowDims,
        dy: &DeviceBuffer, h: &DeviceBuffer, dg: &DeviceBuffer) -> Step;
    // NOTE deliberately absent: step_gate_dx — dx = dy is the identity (§1).
}
```

Uniform params per step (`gpu.step(kind, bufs, params, threads)`); all
params are plain u32 (this family has NO f32 uniform):

| step            | params                   | threads              |
|-----------------|--------------------------|----------------------|
| `film_chan`     | `[n, c, h, w]`           | `n*c*h*w`            |
| `film_chan_dx`  | `[n, c, h, w]`           | `n*c*h*w`            |
| `film_chan_dsb` | `[n, c, h, w]`           | `n*c`                |
| `film_row`      | `[r, d, rows_per_cond]`  | `r*d`                |
| `film_row_dx`   | `[r, d, rows_per_cond]`  | `r*d`                |
| `film_row_dsb`  | `[r, d, rows_per_cond]`  | `(r/rows_per_cond)*d`|
| `gate_row`      | `[r, d, rows_per_cond]`  | `r*d`                |
| `gate_row_dh`   | `[r, d, rows_per_cond]`  | `r*d`                |
| `gate_row_dg`   | `[r, d, rows_per_cond]`  | `(r/rows_per_cond)*d`|

## 8. Edge cases

- `R % rows_per_cond != 0` → `FilmRowDims::new` returns `Err` (kernels
  ASSUME divisibility; a ragged final group is undefined and unreachable).
- Any zero dim → `Err` from the validated constructors.
- `rows_per_cond = 1` → per-row conditioning (`NC = R`, `g(r) = r`).
- `rows_per_cond = R` → one condition for the whole sequence (`NC = 1`,
  classic adaLN). Both extremes must work (covered by FD shapes and/or the
  identity test — no dedicated test required beyond §10).
- `H = W = 1` (chan) / `rows_per_cond = 1` (row): the `dsb` reductions have
  a single term — no special casing.
- `s = b = 0` ⇒ FiLM is the identity; `g = 0` ⇒ gate is the identity on
  `x`. Required property test §10.7 (`==` equality; `-0.0 == 0.0` makes the
  assertion safe even at signed zeros).
- No eps, no division, no sqrt anywhere: no NaN/inf paths for finite inputs.
- Thread counts exceeding one dispatch row: covered by the standard 2D-grid
  index recipe; not separately tested at this unit's tiny shapes.

## 9. Gradcheck entries

Kernel-level FD tests in this unit's test file (the
`crates/gradcheck/tests/mse_fd.rs` pattern — NOT a `CheckModel`
registration; this unit has no trainable model). Global tolerances
(playbook §3, never loosened): `h = 5e-3`, pass iff
`|analytic − numeric| ≤ 4e-3 + 8e-2·max(|a|,|n|)` per direction. Scalar
loss `L = Σ_i w_i · y_i` with a fixed LCG-seeded weight vector `w`; the
backward kernels run with `dy := w`. Required entries:

1. **chan**: perturb `x` (compare `⟨dx, v⟩` to `(L(x+hv)−L(x−hv))/2h`) and
   perturb `sb` (compare `⟨dsb, v⟩`), ≥ 2 random directions each.
2. **row**: same two checks on the row variant.
3. **gate**: perturb `h` (`⟨dh, v⟩`), perturb `g` (`⟨dg, v⟩`), and perturb
   `x` (`⟨dy, v⟩` — validates the documented `dx = dy` identity with NO
   kernel dispatched).

## 11. Determinism

- Every output element is written by exactly ONE thread with `=`; no
  atomics, no barriers, no shared memory; write sets are disjoint within
  and across the dispatches of a backward pass (`dx`/`dsb`, `dh`/`dg`).
- The only reductions (`film_chan_dsb`, `film_row_dsb`, `gate_row_dg`) are
  per-thread sequential loops in a FIXED ascending order (`(h,w)` /
  `i in 0..rows_per_cond`); fp32 summation order is identical on every run
  ⇒ bitwise-reproducible outputs on a given backend (test §10.11 enforces
  this on the CPU backend).
- Cross-backend (CPU vs wgpu/Vulkan) parity is NOT required to be bitwise
  (fma contraction differs), only tolerance-level; gating is CPU-only.
- No RNG, no eps, no order-dependent accumulation across threads anywhere
  in this family.
