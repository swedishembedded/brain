## 1. Purpose

GroupNorm over NCHW activations for the DIAMOND denoiser/upsampler UNets
(and any future conv model). Matches PyTorch `nn.GroupNorm(G, C, eps)`
semantics with **population (biased) variance**, normalizing each `(n, g)`
group over its `C/G` channels × `H*W` spatial positions, then applying a
per-channel affine `gamma, beta`.

DIAMOND convention (decided by the CALLER, never inside these kernels or the
host wrapper): `num_groups = max(1, C / 32)`. `eps` is a runtime parameter
(DIAMOND uses the PyTorch default `1e-5`), passed as f32 bits in the uniform
(the `gpu_core::f` convention, `bitcast<f32>` in WGSL — see
`bn_running.wgsl` for the precedent).

Decomposition mirrors the `bn_*` family: a stats kernel, an apply kernel,
two parameter-grad reductions, a per-group backward reduction, and a
per-element `dx` kernel. All kernels: fp32 only, uniform `Params` at
`@binding(0)`, ≤ 4 storage buffers, `@workgroup_size(64)`, no atomics /
barriers / f16, no f32 `%` (u32 `%` and `/` are fine), 2D-grid-safe linear
thread index `gidx = gid.y * (nwg.x * 64u) + gid.x`.

## 2. Shapes, layouts, index conventions

Tensor `x[N, C, H, W]`, row-major NCHW:

```
idx(n,c,h,w) = ((n*C + c)*H + h)*W + w
```

Derived quantities (u32 arithmetic):

```
cpg = C / G                    // channels per group; REQUIRES C % G == 0
M   = cpg * H * W              // elements per (n,g) group, as f32 in kernels
group of channel c:   g = c / cpg
group index:          k = n*G + g          // k in [0, N*G)
from element idx:     hw = H*W;  c = (idx / hw) % C;  n = idx / (C*hw)
from thread k (stats/dsum kernels): n = k / G;  g = k % G
```

Buffers (all `array<f32>`):

| name    | length      | layout                                                                 |
|---------|-------------|------------------------------------------------------------------------|
| `x`     | `N*C*H*W`   | NCHW input                                                             |
| `y`     | `N*C*H*W`   | NCHW output (fresh SSA buffer; doubles as bwd-time reference if needed) |
| `gb`    | `2C`        | **concatenated** affine params: `gb[c] = gamma[c]` (c < C), `gb[C+c] = beta[c]` |
| `stats` | `2*N*G`     | `stats[2k+0] = mean[k]`, `stats[2k+1] = rstd[k]` with `k = n*G+g`       |
| `dy`    | `N*C*H*W`   | upstream gradient                                                      |
| `dyg`   | `N*C*H*W`   | scratch: `dyg = dy * gamma[c]` (produced by the existing `scale_chan`)  |
| `sums`  | `4*N*G`     | `sums[4k+0]=mean[k]`, `sums[4k+1]=rstd[k]` (copied through), `sums[4k+2]=S1[k]`, `sums[4k+3]=S2[k]` |
| `dx`    | `N*C*H*W`   | input gradient                                                         |
| `dgb`   | `2C`        | parameter grads, same layout as `gb`: `dgb[c] += dgamma[c]`, `dgb[C+c] += dbeta[c]` |

Design notes:

- `gb` is **concatenated** (`gamma` first, then `beta`) — deliberately NOT the
  interleaved `[2c]/[2c+1]` packing bn uses — so the existing `scale_chan`
  kernel (`out[idx] = x[idx] * scale[(idx/inner) % c]`) can read `gamma`
  directly from `gb` (it only ever indexes `[0, C)`). That is what keeps the
  backward chain at ≤ 4 storage buffers per kernel without a new `gn_dyg`
  kernel.
- `stats` stores `rstd = 1/sqrt(var + eps)` (not `var`): eps enters in exactly
  one kernel (`gn_stats`), and every consumer multiplies.
- `sums` copies `mean`/`rstd` through (bn_dstats precedent) so `gn_dx` needs
  only `{x, dyg, sums, dx}` = 4 storage buffers.
- `dgb` is ACCUMULATED (`+=`, pre-zeroed by the caller via `submit` clears or
  an explicit zero write), matching `bn_dgamma`/`bn_dbeta`, so grads compose
  with grad-accumulation.

## 3. Math

Forward, for each group `k = (n,g)` with member set
`Ω(k) = {(n,c,h,w) : c ∈ [g*cpg, (g+1)*cpg)}`, `|Ω| = M`:

```
mean_k = (1/M) Σ_{Ω(k)} x
var_k  = (1/M) Σ_{Ω(k)} (x - mean_k)^2          // population/biased
rstd_k = 1 / sqrt(var_k + eps)                   // eps INSIDE the sqrt
xhat_i = (x_i - mean_k(i)) * rstd_k(i)
y_i    = gamma_{c(i)} * xhat_i + beta_{c(i)}
```

Backward, given `dy = dL/dy`:

```
dbeta_c  = Σ_{n,h,w} dy_i                        // per channel
dgamma_c = Σ_{n,h,w} dy_i * xhat_i               // per channel
dyg_i    = dy_i * gamma_{c(i)}                   // = dL/dxhat
S1_k     = Σ_{Ω(k)} dyg_i
S2_k     = Σ_{Ω(k)} dyg_i * xhat_i
dx_i     = rstd_k * ( dyg_i − S1_k/M − xhat_i * S2_k/M )
```

Derivation sketch (standard): `dL/dvar` and `dL/dmean` folded into the two
group sums; identical in form to BatchNorm backward with the reduction taken
over the group `Ω(k)` instead of over `(n,h,w)` per channel.

Useful invariant (holds for any eps, used as a test sanity check):
`Σ_{Ω(k)} dx_i = 0` for every group `k` (since `Σ_Ω xhat = 0` and the `S1`
term subtracts the mean of `dyg`). NOTE: `Σ_Ω dx_i * xhat_i = 0` holds only
at `eps = 0` — do NOT assert it for eps > 0.

## 4. Kernel contracts

Common: `@workgroup_size(64)`, thread index
`gidx = gid.y * (nwg.x * 64u) + gid.x`, bounds-check and return. Uniform
`Params` at `@group(0) @binding(0)`. Every kernel takes the SAME five u32
dims `{N, C, H, W, G}` (a field may be unused — keep the layout uniform);
`gn_stats` additionally carries `eps` as f32 bits. Host passes params as
`&[u32]` in struct field order.

### 4.1 `gn_stats` — one thread per (n,g), `N*G` threads

```
Params { N, C, H, W, G, eps: u32 /* bitcast<f32> */ }
b1 x     : read        [N*C*H*W]
b2 stats : read_write  [2*N*G]
```

Thread `k`: `n = k/G`, `g = k%G`. Two sequential passes over `Ω(k)` in
ascending `(c, h, w)` order (c from `g*cpg` to `(g+1)*cpg`), exactly like
`bn_stats`: first accumulate `mean`, then `var`. Writes
`stats[2k] = mean_k`, `stats[2k+1] = 1.0/sqrt(var_k + bitcast<f32>(eps))`
(use `inverseSqrt`).

### 4.2 `gn_apply` — one thread per element, `N*C*H*W` threads

```
Params { N, C, H, W, G }
b1 x     : read        [N*C*H*W]
b2 stats : read        [2*N*G]
b3 gb    : read        [2C]     (gamma at [c], beta at [C+c])
b4 y     : read_write  [N*C*H*W]
```

`y[idx] = gb[c] * (x[idx] - stats[2k]) * stats[2k+1] + gb[C+c]`.

### 4.3 `gn_dgamma` — one thread per channel, `C` threads

```
Params { N, C, H, W, G }
b1 x     : read        [N*C*H*W]
b2 dy    : read        [N*C*H*W]
b3 stats : read        [2*N*G]
b4 dgb   : read_write  [2C]
```

`dgb[c] = dgb[c] + Σ_{n,h,w} dy[i] * (x[i] - mean_k)*rstd_k` with
`k = n*G + c/cpg` (mean/rstd re-read per n). Ascending `(n,h,w)` loop order.
Writes ONLY `dgb[c]` (the gamma half). ACCUMULATES.

### 4.4 `gn_dbeta` — one thread per channel, `C` threads

```
Params { N, C, H, W, G }   // G unused, kept for layout uniformity
b1 dy  : read        [N*C*H*W]
b2 dgb : read_write  [2C]
```

`dgb[C+c] = dgb[C+c] + Σ_{n,h,w} dy[i]`. Writes ONLY `dgb[C+c]` (the beta
half). ACCUMULATES. Disjoint from `gn_dgamma`'s writes, so both dispatches
may share one submit.

### 4.5 `gn_dsum` — one thread per (n,g), `N*G` threads

```
Params { N, C, H, W, G }
b1 x     : read        [N*C*H*W]
b2 dyg   : read        [N*C*H*W]   (scale_chan output, see §5)
b3 stats : read        [2*N*G]
b4 sums  : read_write  [4*N*G]
```

Thread `k`: single pass over `Ω(k)` (ascending `(c,h,w)`), accumulating
`S1 += dyg[i]` and `S2 += dyg[i] * (x[i]-mean_k)*rstd_k`. Writes
`sums[4k] = mean_k`, `sums[4k+1] = rstd_k` (copied from `stats`),
`sums[4k+2] = S1_k`, `sums[4k+3] = S2_k`.

### 4.6 `gn_dx` — one thread per element, `N*C*H*W` threads

```
Params { N, C, H, W, G }
b1 x    : read        [N*C*H*W]
b2 dyg  : read        [N*C*H*W]
b3 sums : read        [4*N*G]
b4 dx   : read_write  [N*C*H*W]
```

```
mean = sums[4k]; rstd = sums[4k+1]; S1 = sums[4k+2]; S2 = sums[4k+3]
xhat = (x[idx] - mean) * rstd
dx[idx] = rstd * (dyg[idx] - S1/M - xhat * S2/M)      // M = f32(cpg*H*W)
```

OVERWRITES `dx` (not accumulate) — callers needing accumulation add
separately (SSA convention).

## 5. `dyg` via the existing `scale_chan`

`scale_chan` (`crates/kernels/wgsl/scale_chan.wgsl`) computes
`out[idx] = x[idx] * scale[(idx / inner) % c]` with
`Params { total, c, inner }`. Verified semantics: exactly the per-channel
broadcast we need. Dispatch it with:

```
bufs   = [dy, gb, dyg]            // gb passed as the `scale` buffer
params = [N*C*H*W, C, H*W]
threads = N*C*H*W
```

Since `(idx/inner) % c ∈ [0, C)`, only the gamma half of `gb` is ever read.
No new kernel and no kernel fork is needed.

## 6. Backward dispatch order

```
1. scale_chan (dy, gb        -> dyg)
2. gn_dsum    (x, dyg, stats -> sums)
3. gn_dx      (x, dyg, sums  -> dx)
4. gn_dgamma  (x, dy, stats  -> dgb[0..C))      accumulate
5. gn_dbeta   (dy            -> dgb[C..2C))     accumulate
```

2 must follow 1; 3 must follow 2; 4 and 5 are independent of 1–3 and of each
other (disjoint writes). One `gpu.submit` of all five steps in this order is
the reference sequence.

## 7. Hand-computed reference (N=1, C=4, G=2, H=W=2, eps=1.0)

`cpg = 2`, `M = 2*2*2 = 8`. eps is deliberately 1.0 (not 1e-5) so the test
proves eps is READ FROM PARAMS, and so `rstd` is exact.

Input `x` (each channel listed in `(h,w)` row-major order, i.e. flat index
`c*4 + h*2 + w`):

```

c1 = [ 5, 6, 7, 8]        beta  = [0.5, -1.0, 0.0, 2.0]
c2 = [-1, 1, 1, 1]        => gb  = [2.0, 0.5, 1.0, -1.0,  0.5, -1.0, 0.0, 2.0]
```

## 8. Host API (`crates/wm-core/src/gn.rs`)

New crate `brain-wm-core` (lib name `wm_core`), workspace member +
default-member + `workspace.dependencies` entry. Depends on
`brain-gpu-core`, `brain-kernels`.

```rust
/// Dims + hyperparams of one GroupNorm site. eps is a runtime param.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct GnDims { pub n: u32, pub c: u32, pub h: u32, pub w: u32, pub g: u32, pub eps: f32 }

impl GnDims {
    pub fn new(n: u32, c: u32, h: u32, w: u32, g: u32, eps: f32) -> Result<GnDims, String>;
        // Err if any of n,c,h,w,g == 0, or c % g != 0, or eps <= 0.0
    pub fn elems(&self) -> u32;      // n*c*h*w
    pub fn groups(&self) -> u32;     // n*g   (thread count for stats/dsum)
    pub fn stats_len(&self) -> u64;  // 2*n*g (f32 elements)
    pub fn sums_len(&self) -> u64;   // 4*n*g
}

/// DIAMOND group-count convention: max(1, c/32). The CALLER decides; the
/// kernels take whatever G they are given.
pub fn num_groups(c: u32) -> u32;

/// Kernel-table indices in the caller's `Gpu` (optim::Optim precedent).
/// `scale_chan` is the EXISTING kernel reused for dyg.
#[derive(Clone, Copy, Debug)]
pub struct Gn {
    pub stats: usize, pub apply: usize, pub dgamma: usize,
    pub dbeta: usize, pub dsum: usize, pub dx: usize, pub scale_chan: usize,
}

impl Gn {
    /// (name, source) pairs for Gpu::new, in the order matching Gn::seq().
    /// ["gn_stats","gn_apply","gn_dgamma","gn_dbeta","gn_dsum","gn_dx","scale_chan"]
    pub fn kernel_sources() -> [(&'static str, &'static str); 7];
    /// Gn with indices 0..=6 matching kernel_sources() order.
    pub fn seq() -> Gn;

    /// Steps [gn_stats, gn_apply]. Caller submits.
    /// Panics (debug_assert) if buffer roles mismatch is not detectable — dims
    /// are trusted; d must come from GnDims::new.
    pub fn forward(&self, gpu: &Gpu, d: &GnDims,
        x: &DeviceBuffer, gb: &DeviceBuffer,
        stats: &DeviceBuffer, y: &DeviceBuffer) -> Vec<Step>;

    /// Steps [scale_chan, gn_dsum, gn_dx, gn_dgamma, gn_dbeta] (§6 order).
    /// `stats` is the forward-pass stats buffer (SSA cache). `dgb` must be
    /// pre-zeroed by the caller (e.g. via submit clears) unless accumulating.
    pub fn backward(&self, gpu: &Gpu, d: &GnDims,
        x: &DeviceBuffer, gb: &DeviceBuffer, stats: &DeviceBuffer,
        dy: &DeviceBuffer, dyg: &DeviceBuffer, sums: &DeviceBuffer,
        dx: &DeviceBuffer, dgb: &DeviceBuffer) -> Vec<Step>;
}
```

Uniform params per step (`gpu.step(kind, bufs, params, threads)`,
`f = gpu_core::f`):

| step         | params                                   | threads     |
|--------------|------------------------------------------|-------------|
| `gn_stats`   | `[n, c, h, w, g, f(eps)]`                | `n*g`       |
| `gn_apply`   | `[n, c, h, w, g]`                        | `n*c*h*w`   |
| `scale_chan` | `[n*c*h*w, c, h*w]`                      | `n*c*h*w`   |
| `gn_dsum`    | `[n, c, h, w, g]`                        | `n*g`       |
| `gn_dx`      | `[n, c, h, w, g]`                        | `n*c*h*w`   |
| `gn_dgamma`  | `[n, c, h, w, g]`                        | `c`         |
| `gn_dbeta`   | `[n, c, h, w, g]`                        | `c`         |

## 9. Edge cases

- `C % G != 0` → `GnDims::new` returns `Err` (kernels ASSUME divisibility;
  behavior with non-divisible C,G is undefined and must be unreachable).
- `G = 1` → LayerNorm-over-(C,H,W) per sample. Must work (covered by FD test
  shapes if convenient; not a required separate test).
- `G = C` (cpg = 1) → InstanceNorm per (n,c). Required property test §10.5.
- `M = 1` (G=C, H=W=1): var = 0, `rstd = 1/sqrt(eps)`, `xhat = 0`, `y = beta`
  broadcast; `dx = rstd*(dyg − dyg − 0) = 0`. No NaN/inf as long as eps > 0
  (enforced by `GnDims::new`).
- Constant input within a group: var = 0 → `rstd = 1/sqrt(eps)` finite.
- eps: strictly `rstd = 1/sqrt(var + eps)` — INSIDE the sqrt, added to var.
  Required placement test §10.4.
- Thread counts exceed one dispatch row: covered by the standard 2D-grid
  index recipe; not separately tested at this unit's tiny shapes.
- `num_groups(c)`: `num_groups(1..=63) == 1` except `num_groups(64) == 2`,
  i.e. `max(1, c/32)` with u32 division (`num_groups(95) == 2`,
  `num_groups(96) == 3`).

## 11. Determinism

- Every output element is written by exactly ONE thread; no atomics, no
  barriers, no shared memory, no data races by construction (disjoint write
  sets per kernel; `gn_dgamma`/`gn_dbeta` write disjoint halves of `dgb`).
- All reductions are per-thread sequential loops in a FIXED iteration order
  (ascending `(c,h,w)` for group reductions in `gn_stats`/`gn_dsum`,
  ascending `(n,h,w)` for `gn_dgamma`/`gn_dbeta`). fp32 summation order is
  therefore identical on every run → bitwise-reproducible outputs on a given
  backend (test §10.6 enforces this on the CPU backend).
- Cross-backend (CPU vs wgpu/Vulkan) parity is NOT required to be bitwise
  (different fma contraction), only tolerance-level; gating is CPU-only.
- `dgb` accumulation is deterministic given a deterministic starting buffer;
  callers zero it via `submit` clears.
