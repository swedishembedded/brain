Latency by device

Real per-forecast latency driving each model through the same forecast() seam. CPU (wgsl-cpu Cranelift-JIT + AVX2) is the warm median over the full eval run; GPU (wgpu/Vulkan, Intel Arc) is a warm isolated median; NPU is the accelerator-core time from the dedicated brain npu driver (OpenVINO, /dev/accel/accel0), excluding host pre/post and one-time graph compile. The striking result: these small-context forecasts are dispatch-bound on the GPU (thousands of tiny kernel launches with host↔device syncs), so the CPU is 4–10× faster; the NPU, which runs the whole graph, is faster still. Kronos here uses a 128-bar context (single modal draw); its GPU path was impractically slow to benchmark, and FinCast's 991M-param NPU graph exceeded the compile budget.

Optimization — FinCast MoE gather/scatter

FinCast's sparse MoE computed every expert's FFN over ALL patch tokens, then masked the result on combine — num_experts×s token-MLPs per layer for a top-2 router. The optimization gathers only each expert's routed tokens, runs the expert on that subset, and scatters the weighted result back: top_n×s token-MLPs (here 2/4 of the FFN rows), across all 50 layers. Every expert op (LayerNorm / GEMM / ReLU / bias) is row-independent, so it is bit-identical to the dense path.

Parity: crates/fincast tests::moe_gather_scatter_matches_dense runs a tiny model both ways (FINCAST_MOE_DENSE=1 vs default) and asserts worst |diff| < 1e-4 — exact match, PASS.

How to read this — honesty notes

Small samples are noise-dominated. 27 weekly origins × 15 names is a small sample for a RankIC of order 0.0–0.1. A single cumulative-return line can look impressive or dismal purely by chance; the t-stat is the load-bearing number, and at this n most are indistinguishable from zero.
Scope was bounded by compute, not cherry-picked. All three models ran through one harness on the same universe and weeks. Kronos's ~10 s/forecast CPU cost (and FinCast's 991M-param, 4 GB-per-forward memory pressure) on this shared, swap-saturated box capped the common window; the scope was fixed before looking at results, and every model is scored on the identical cross-section.
Negative control. Shuffling each model's predictions within every week destroys any real signal and should give RankIC ≈ 0. It does — demonstrating the harness manufactures no false skill. A model whose real RankIC is not clearly separated from its own shuffled control has shown no edge.
Contamination. Checkpoints predate 2026, so 2026 bars are genuinely unseen — but these names and their regimes resemble the pretraining distribution. Out-of-time is not out-of-distribution.
Cost is modelled, and it dominates. The L/S curves are net of 5.0 bps/side per weekly rebalance. Zero-cost backtests (e.g. StockMixer) are an upper bound, not a comparison point.
Not financial advice. This is an engineering evaluation of model implementations, not an investment recommendation. Nothing here is a signal to trade.
