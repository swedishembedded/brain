# brain-codec — Qwen3-TTS 12 Hz neural audio codec (Mimi/Moshi-style)

Pure Rust + raw WGSL, fp32, forward-exact against the official
`Qwen3-TTS-Tokenizer-12Hz` checkpoint. Both directions are implemented:

```
wav  --encode-->  codes [T,16]  --decode-->  wav'
```

## Encode (`Codec::encode`, `src/model.rs`)

Mirrors the HuggingFace `MimiModel` encoder (`encoder.*` in the checkpoint):

1. **SEANet conv encoder** (`encoder.encoder.layers.*`) — head conv `1->64 k7`,
   then 4 downsample stages `[4,5,6,8]` (each: a Snakeless ELU residual block +
   an ELU + a strided causal conv `k=2r`), then a tail ELU + conv to
   `hidden=512`. Causal `MimiConv1d` = LEFT pad `effective_kernel - stride`,
   output length `ceil(L/stride)` (`audio::conv`, zero pad on the right).
2. **Encoder transformer** (`encoder.encoder_transformer.layers.*`) — 8 pre-LN
   layers, `nn.LayerNorm` (with bias, eps 1e-5), RoPE GQA (scaling `1/√head_dim`),
   `gelu` MLP `fc2(gelu(fc1))`, per-channel LayerScale. Reuses `model::block`.
3. **Frame-rate-match downsample** (`encoder.downsample`) — replicate-padded
   causal conv, stride 2.
4. **Split-RVQ encode** (`encoder.quantizer.*`) — project `512->256`
   (`input_proj`), then nearest-codebook **argmin + residual subtraction** across
   1 semantic + 15 acoustic codebooks (host loop, like the speaker pooling; no
   kernel was added).

LayerNorm / GELU / ELU and the argmin/residual loop run on the host for
bit-faithfulness; conv / attention run on-device.

**Verification** (`tests/encode.rs`, gated on the real checkpoint):

- **Round-trip** `wav -> encode -> decode -> wav'`: finite, bounded, correct
  length, non-silent.
- **Code-match vs PyTorch** `tokenizer.encode`: **100% (400/400 codes)** on the
  golden dump (`dumps/codec_enc_ref`, generated by
  `tools/goldens/qwen3tts_codec_dump_reference.py` from the upstream `qwen-tts`
  package's own `Qwen3TTSTokenizerV2Model`, fp32 on the CPU).

The encoder closes the in-context-learning (ICL) gap: `tts::pipeline::clone`
now encodes the reference wav in-tree (`Codec::encode`) instead of requiring an
external `--ref-codes` dump.

## Decode (`Codec::decode`)

SplitResidualVectorQuantizer dequant -> pre-conv -> 8-layer GQA transformer
(RoPE/RMSNorm/LayerScale) -> conv-transpose upsample -> SEANet decoder
(SnakeBeta) -> 24 kHz waveform. Parity vs the fp32 PyTorch golden dump (T=24,
CPU backend): max-abs 5.7e-4, log-mel L1 7.7e-4 (see `tests/decode.rs`).

## Reconstruction trainer (`src/recon.rs`, Track C — scope-limited)

The **non-GAN** half of a neural-codec training objective, gradchecked end to
end:

```
wav -> conv encoder -> straight-through VQ -> conv decoder -> wav'
loss = waveform L1+L2  (+ multi-scale log-mel L1, reported)
```

- `waveform_recon` — exact analytic gradient (gradchecked vs finite diff).
- `StraightThroughVq` — nearest-codebook quantize + commitment `β·‖z−sg(q)‖²`;
  the straight-through estimator passes the decoder gradient `q -> z`.
- `ConvReconAE` — tiny causal-conv encoder/decoder over the shared WGSL engine
  (`audio::conv` fwd + `conv1d_dx`/`conv1d_dw` bwd). `gradcheck()` verifies the
  **whole reconstruction path** against central finite differences of the
  straight-through surrogate (frozen VQ assignment): **max rel err ≈ 3.8e-3**.
  `train_step` overfits a toy waveform (loss 0.62 → 0.24).

### Remaining research piece (documented, NOT implemented — no faked results)

The production codec also trains with, on top of the reconstruction loss:

- **Raw-waveform GAN** — multi-period + multi-scale discriminators, adversarial
  + feature-matching losses. *Not implemented* (`// TODO(gan)` in `recon.rs`).
- **WavLM semantic distillation** — *not implemented*.
- **Multi-scale log-mel L1 backward** — `multiscale_mel_l1` is wired as a forward
  *metric* only; its STFT/mel backward is a `// TODO`.

No discriminator metrics are reported because none are computed.
